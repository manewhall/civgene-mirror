Static Mirrors

Please consider running a mirror of The Civilization Gene.  Every night a static archive of the entire site is created.  It can always be downloaded from here.

http://www.matthewnewhall.com/civgene.tar.gz

Simply extract  the directory structure somewhere where a web server will serve it.  The entire mirror is static so nothing else is required.  See the file README.txt in the archive for details.

If you like you can run advertisement banners on the mirror site.  Coding that is up to you.  Contents of the entire archive are licensed under the Creative commons by-nc-nd 3.0 licence.

http://creativecommons.org/licenses/by-nc-nd/3.0/deed.en_US

If you do set up a mirror, please tell me about it and I’ll list the  mirror here for peoples convenience.  Email me at comments@civgene.matthewnewhall.com
